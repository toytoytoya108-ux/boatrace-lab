`preview` の気象は**1つ前のレースの観測値**で、当該レースの本番気象ではない（一致率 99.9%）。締切時点の読みと本番の風が一致するのは 47.2%、1m/s 以上ちがうのが 52.8%。**市場もこの読みで値付けしている。**

探索 〜2026-05-31（22,319R）で風の予測係数とロジット係数を推定し、確認期間（13,932R）で1回だけ評価。

## 4. プラセボ（帰無仮説「市場確率が真」のもとで生成した結果）

**1着をただシャッフルする作りは誤り**だった（艇番の周辺分布と選択集合の対応が壊れ、
選ばれた艇の多くが1号艇なので比が 2.5 前後まで跳ね上がる。最初の実行でそれが出た）。
正しい帰無は「市場確率 q が真の確率」。そこから1着を生成すれば、どんな選び方でも比は 1.0 になるはず。
20回生成した平均を出す。1.0 から離れるなら、手順そのものに偏りがある。

| モデル | 上位2% 比（平均） | 上位2% 比（最大） |
|---|---:|---:|
| M1 艇番のみ | 1.009 | 1.068 |
| M2 ＋風の残差 | 1.016 | 1.099 |
| M3 ＋締切時点の風 | 1.001 | 1.046 |

## 判定（基準は実行前に固定済み・コミット efa2f1b）

1. M2 の対数損失 < M1: M1 1.1444 / M2 1.1444 → **合格**（ただし差は +0.0000 nats）
2. M2 の上位2%比 > M1: M1 0.935 / M2 1.009 → **合格**
3. プラセボで再現しない: 上表のとおり帰無のもとで比はほぼ 1.0 → **合格**
4. 上位2%の n ≥ 500: n=1,865 → **合格**
5. **継続基準 p/q 上位1〜2% ≥ 1.20**: 上位2% 1.009 / 上位1% 1.022 → **不合格**

### 結論
風は確かに予測できる（確認期間で RMSE 1.1135 → 1.0113）。
しかし**市場の値段を条件づけたあとに残る価値は +0.0000 nats** で、
控除率25%を埋めるのに必要な 0.2877 nats の **0.01%** しかない。

理由は2つ。
- 風の残差が大きいレースが少ない（|r|≥1.0m/s は 2.5%）
- 1m/s の差が1着確率を動かす量が、市場が既に知っていることに比べて小さい

**予測できること（RMSE −9%）と、値段に対して価値があることは別だった。**
基準5で不合格なので、風向での精緻化には進まず、アイデアDはここで打ち切る。
