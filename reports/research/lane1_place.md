## 5. 場の差は本物か（探索 2018〜23 → 確認 2024〜26）

- **場別回収率の順位相関 ρ = +0.645**。帰無200回（両期間で場ラベルを無作為化）は -0.363〜+0.364 で、実測以上は **0/200**。
  → **場ごとの差は本物で、期間をまたいで引き継がれる。**
- 何が効いているか: **1号艇の2連対率と回収率の相関 +0.309**（元返しの割合とは -0.021）。
  → **強さでは説明できない。** 元返し（100円下限）との関係も弱く、場の差の中身は未解明。

| 探索で上位k場を選ぶ | k=1 | k=3 | k=5 | k=8 |
|---|---:|---:|---:|---:|
| 過去の回収率が高い順 | 98.8% | 96.9% | 96.4% | 96.2% |
| 1号艇の2連対率が高い順 | 95.2% | 92.6% | 94.1% | 93.9% |
| （対照）全場 | 93.9% | | | |

**1号艇の2連対率で選んだ上位3場（大村・徳山・芦屋）は確認期間 92.6%。** 無作為に3場選ぶ200回は 91.0〜96.6%（中央 94.0%）なので、**無作為の範囲の外**＝前向きに使える差ではある。

## まとめ

1. **全場 94.5%**（473,775R、的中 72.5%、元返し 46.3%）。**最高 江戸川 100.03% ／ 最低 戸田 89.9%**。これは `sweet_spot.md` の複勝（市場の確信度上位10%）99.1% に次ぐ水準で、**本プロジェクトの固定ルールとしては最も100%に近い**。
2. **江戸川 の 100.03% は「100%を超えている」とは言えない。** 95%区間の下限が 98.0%、100%以上の年は 5/9、探索 100.6% → 確認 98.8%。**9年17,928レースかけて「ほぼ収支トントン」が確認できた、という結果。**
3. **場の差そのものは本物**（ρ=+0.645、帰無200回で実測以上は 0/200）。ただし**1号艇の強さでは説明できない**（2連対率との相関 +0.309、元返しとは -0.021）。中身は未解明で、`stadium_study.md` が2026年のみでは見つけられなかった構造がここにある。
4. **2号艇（86.2%）より 8.3pt 良い。** 艇番が外になるほど単調に落ちるので、**複勝で狙うなら1号艇が正解**。
5. **規模の問題は解決しない。** 江戸川 は1日約7.3レース、100円で期待利益はほぼゼロ。金額を上げれば自分でオッズを潰す（`sweet_spot.md` と同じ壁）。
