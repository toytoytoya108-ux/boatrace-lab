# 飛躍18: 1号艇複勝の「場の差」の正体（473,775レース・2018〜2026）

`lane1_place.md`: 場ごとの回収率の差は本物（探索→確認 ρ=+0.645、帰無200回で 0/200）だが、
**1号艇の強さ（相関 +0.309）でも元返し（−0.021）でも説明できなかった。** その中身を割る。

## 1. まず市場がどれだけ織り込んでいるかを測る

`log(回収率) = log(的中率) + log(払戻/100)`。市場が場ごとの強さを完全に織り込むなら
**払戻 ∝ 1/的中率**（傾き −1.00）で、回収率は場によらず一定になる。

- **実測の傾き = -0.864**（完全な織り込みなら −1.00）
- log(的中率) と log(払戻) の相関 = **-0.920**
- 分散: 回収率 0.00060 ＝ 的中率 0.00388 ＋ 払戻 0.00342 ＋ 2×共分散 -0.00670

→ **市場は場ごとの強さをほぼ完全に打ち消している。** 的中率の分散と払戻の分散が
ほぼ相殺し、回収率の分散は 15% しか残らない。
**織り込み不足は傾きの +13.6% ぶんだけ**（−0.864 なので、的中率が1%高い場では
払戻が 0.86% しか下がらない ＝ 強い場がわずかに得）。
**「場の差」と呼んでいたものの正体は、この小さな取りこぼしと、次の残差。**

### 残差は本物か（探索2018〜23 → 確認2024〜26）

- 順位相関 **ρ = +0.605**。帰無2000回（探索側の残差を無作為に並べ替え）は -0.404〜+0.405 で、**実測以上は 3/2000**。
- 残差は場別回収率の **R² = 0.880** を説明する。

→ **場固有の値付けの癖は9年間ずっと同じ向きで残っている。** これが「場の差」の本体。

**見かけ上効いていた2つ（不成立率 +0.625、年間レース数 −0.532）は、江戸川を外すと消える**
（+0.245 / −0.258）。**江戸川1場が両方の外れ値だっただけ。**
江戸川は不成立率 7.6%（多摩川は 0.2%）で唯一の河川・感潮コース。**残差も最大（+0.067）。**
残りの23場の残差は、測れる属性のどれとも関係しない。

→ **「場の固定効果」としか言いようがない。実在して持続するが、中身は説明できない。**

## まとめ: 飛躍18

1. **市場は場ごとの強さをほぼ完全に織り込んでいる。** 傾き -0.864（完全なら −1.00）、相関 -0.920。的中率と払戻の分散がほぼ相殺し、回収率の分散は15%しか残らない。**「場の差」は大きな相殺のあとの残りかす。**
2. **その残りかすは本物。** 傾きで説明できない場固有の残差が探索→確認で ρ=+0.605（帰無 3/2000）、回収率の場差の R²=0.880 を説明する。
3. **正体は説明できない。** 万舟率・ナイター・不成立率・規模・強さ・SG比率・元返し、
   どれも江戸川を外すと相関が消える。**江戸川という1つの外れ値と、23場の構造の無いばらつき。**
4. **前向きには使える**（上位8場で +2.3pt、無作為の外）**が、天井は97〜99%で100%に届かない。**
5. 意味するところ: **これは「市場を超える情報」ではなく「市場の値付けの癖」の一種**で、
   `leaps4.md` の「出やすい目ほど安い」と同じ棚に入る。比 1.16 が上限だったのと同様、
   場の癖も +2.3pt が上限。**必要な 1.333 には遠い。**
