## §1 先に共有すべきこと: 競艇での結論と、競輪への持ち込み

本リポジトリは競艇で「期待値1以上の買い目を買い続けて回収率100%超え」を検証してきた。
競輪は**控除率25%一律（全券種）で競艇と同条件**（`reports/research/other_sports.md`）。以下は競輪でも
同じ形で効くと考えている（**仮説**。競輪データで確認するまでは事実として扱わない）。

| 競艇での実測 | 競輪への含意 |
|---|---|
| 必要な歪み: 実際の的中確率 ÷ 市場確率 ≥ **1.333**（＝1/0.75） | 競輪も同じ 1.333 |
| モデルが「期待値1.0以上」と判定した買い目の実回収率 **69.8〜76%**（winner's curse） | 「予想確率×オッズ ≥ 1」を素直に実装すると、ほぼ確実に同じ現象が起きる |
| 市場オッズとモデルを最尤で合成すると、市場の重み0.93・モデル0.15。合成後に期待値1.0超えは 170万買い目中12件 | 「予想確率 ＞ 市場確率」の買い目は、確率を正しく推定するほど消える |
| 市場の歪みの上限は比 **1.14〜1.16**（人気薄過大評価・本命過小評価） | 競輪でも favorite-longshot bias は出る可能性が高いが、1.333 に届くかは未知 |
| 確定オッズで選んだ検証は先読みになる（締切前→確定で当たり目のオッズが中央値 −7〜15% 下がる） | 競輪でも**締切前オッズの記録が必須**。確定オッズだけの検証は楽観に偏る |
| 最良の規則（複勝・本命）で 98〜101%、経済的価値ほぼゼロ | 3連単で100%超えはさらに難しい（的中率が低く分散が大きい） |

**この表から言えること**: 依頼の中心思想「予想確率 ＞ 市場確率の買い目を探す」は正しい問いの立て方である。
ただし競艇では、**その差を作れる私的情報が無かった**ことで止まった。競輪で違いが出るとすれば、
競艇には無い **ライン（並び）という構造情報** を、市場が正しく値付けできていない場合だけである。
したがって分析計画の中心は「ライン情報は市場確率を超える情報を持つか」に置く（§6）。

もう1点、依頼文の例「予想確率10%×15倍＝期待値1.5」は、市場確率に直すと 0.75/15＝5% の目を
10% と見ている（比2.0）ことを意味する。**競艇で見つかった最大の歪みの約1.7倍**であり、
このような買い目がモデル上に出たら、まずモデルの過信を疑う設計にする。

## §5 STEP 4・5: 期間・レース数・品質 —— **未実施**

データが無いため確認できていない。データ入手後に以下を必ず行う（競艇で実際に誤った箇所を含む）。

1. 年別・場別・グレード別・車立て別のレース数、欠損率
2. 払戻の照合: 3連単の「的中目の確定オッズ×100」と公式払戻の一致率（競艇・地方競馬は 98〜99.5% 一致）

4. 同着・複数払戻の扱い
5. Σ(1/確定オッズ) の逆数で実効払戻率を測り、公表の75%と比べる（オッズの切り捨て表示で数pt変わる）
6. 選手照合: 登録番号の重複・欠番、級班変更の時期
7. 並び予想の出典・取得時刻の記録があるか

## §6 STEP 6: 分析計画

競艇と同じ手順で行う。**探索期間と確認期間を時系列で分け、確認期間は1回だけ評価する。
採用条件はデータを見る前に書いて固定する。** 帰無仮説（市場確率が真）からの模擬データで、
同じ探索をしたら偶然どれだけ良く見えるかを毎回測る。

### A. 払戻と人気だけでできる分析（オッズ不要・最初に行う）
結果ページの「3連単の払戻」と「3連単人気」があれば、全組合せオッズが無くても以下が出せる。

- 人気帯別（1 / 2〜5 / 6〜10 / 11〜20 / 21〜50 / 51〜100 / 100〜）の
  的中率・平均払戻・中央値・最大・分散・**回収率**（＝その帯を毎レース全部買った場合）
  - 依頼文 §6 の表そのもの。競艇ではこれで favorite-longshot bias が単調に出た
- 固定の決め打ち規則の回収率（例: 競走得点1位→2位→3位、ライン先頭→番手→3番手）
  - 規則が出走表だけで決まれば、何年分でも使える（競艇は 47万レースをこれで使った）
- 車立て別（7車/9車）・グレード別・場別・年別の安定性

### B. 締切前オッズが必要な分析
- 市場確率 q = (1/オッズ) / Σ(1/オッズ) と実際の的中率の比（校正表）
- 市場確率をオフセットに置いた条件付きロジット `score = log q + γ·z` で、
  特徴量 z が**市場を超えて**持つ情報量（nats）を直接測る。競艇の目的1と同じ物差し
- 必要量は −log(0.75) = 0.2877 nats。競艇の最良は 0.0023 nats だった

### C. ライン（本プロジェクトの核心）
仮説（**未検証**）: 市場はラインを「並び予想」として知っているが、ラインの強さの数値化は粗く、
特に「番手の差し」「3番手の流れ込み」「別線の突っ込み」の確率を誤って値付けしている可能性がある。

測るもの:
1. ライン決着率（1・2着が同ライン、1・2・3着が同ライン）を、ライン人数・ライン合計得点・得点差で層別
2. 「先頭→番手→3番手」の目の市場確率と実績の比
3. 番手1着率・先行残り率の、市場の値付けとのズレ
4. ライン特徴量の、市場を超えた情報量（B と同じ物差し）

### D. 予想モデル（依頼文 §11 の A〜E）
B・C の結果を見てから作る。**モデルの期待値ではなく、市場で較正した確率で期待値を出す**
（§1 の winner's curse 対策）。見送り閾値・資金配分（1レース3,000円以内）はその後。

### 判定基準（事前に固定する案。承認をもらってから確定）
- 確認期間で回収率 > 100%、かつブートストラップ95%区間の下限 > 100%
- 年別・場別で特定の1年・1場に依存しない（除いても崩れない）
- 上位10本の払戻を除いても崩れない
- 帰無模擬データで同じ探索をした場合の最大値を上回る
